Yohta character parts

Seven separate transparent PNGs extracted from your original sheet without resizing or repainting.
Each has 8 pixels of transparent padding. Left/right names use the viewer perspective.
parts.json records original sheet coordinates and image sizes. These coordinates describe the source sheet, not assembled character positions.
The head includes ears, hair, muzzle and mouth. The body includes limbs and paws. Separating these further requires cutting and drawing the hidden areas.
Near-invisible specks outside each crop are omitted; pixels inside each crop preserve original RGBA values.
